A single fortune-cookie line for a crypto trader who was just liquidated — oracular, warm, and funny about the loss instead of cruel about it. The program is fully deterministic: every run writes the same one-line fortune to `/output/entry.txt`.

## The fortune

> Your fortune: from rock bottom, every direction is up — the market took your coins, not your courage.

Eighteen words, 101 characters. It opens with the classic fortune-cookie voice ("Your fortune:"), names the loss and the trader, then turns the lowest point into the punchline: from rock bottom, the only way left is up — and what the market took was the coins, never the courage.

## Run it

```sh
python3 main.py
```
